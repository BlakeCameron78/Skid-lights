# Skidlights

Phone control for SP105E Bluetooth LED controllers (Magic LED app hardware).

Open **https://blakecameron78.github.io/Skid-lights/** in **Bluefy – Web BLE Browser** on iPhone (Safari can't do Bluetooth), or Chrome/Edge on a laptop or Android.

- Multiple controllers, named and targeted (Reverse, Left, Right)
- Live effects: strobe, alternate, fade, breathe, heartbeat, flicker, fire, lightning, sound-reactive, G-force
- OBD2 shift light (BLE ELM327 dongle) with demo sweep
- Presets, show playlist, Track mode with hold-to-flash

Close Magic LED before connecting; each controller only accepts one connection.
